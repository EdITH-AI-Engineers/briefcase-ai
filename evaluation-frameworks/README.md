# evaluation-frameworks/

Ground-truth PDFs and OCR artifacts for the framework bundle used by `genai-analysis`. This directory lives **outside** `genai-analysis/` on purpose — its contents must not be picked up by the framework loader (which walks `genai-analysis/frameworks/manifest.json` only). Keeping it separate prevents raw OCR text (noisy, ~100KB per doc) from leaking into the LLM system prompt.

## Contents

```
evaluation-frameworks/
  pdfs/
    cmo-25-s2015.pdf        Wayback snapshot of CHED CMO 25 s.2015 (scanned, 57 pages)
    cmo-87-s2017.pdf        Wayback snapshot of CHED CMO 87 s.2017 (text-layer + scanned mix, 81 pages)
  ocr/
    cmo-25-s2015.ocr.txt    Tesseract 5 OCR output, whole PDF, with page markers
    cmo-87-s2017.ocr.txt    Tesseract 5 OCR output, whole PDF, with page markers
    *.png                   Rasterized page images (300 DPI, generated by pdftoppm)
  scripts/
    ocr.mjs                 Small Node driver that runs tesseract.js over the PNGs
  package.json              tesseract.js 5.x dependency (Node + WASM)
```

## Reproducing the OCR

```
cd evaluation-frameworks
# Rasterize (only needed once per PDF):
pdftoppm -r 300 -png pdfs/cmo-25-s2015.pdf ocr/cmo25-page
pdftoppm -r 300 -png pdfs/cmo-87-s2017.pdf ocr/cmo87-page
# OCR:
npm install           # pulls tesseract.js
node scripts/ocr.mjs cmo25 cmo-25-s2015.ocr.txt
node scripts/ocr.mjs cmo87 cmo-87-s2017.ocr.txt
```

A ~60-page PDF takes ~2–3 minutes on a modern laptop. The resulting `.txt` has one block per page delimited by `===== PAGE N (filename) =====`.

## Why we OCR

CHED publishes its Memorandum Orders as scanned PDFs generated by `Avision Button Manager` (200–300 DPI, no text layer). Bundle `v1.2.x` and earlier relied on the widely-circulated CHED-PSG outcome template to paraphrase program outcomes; that template, it turns out, introduces outcomes that do not exist in the canonical CMO (e.g. `bscs-po-11` through `bscs-po-14`). OCR lets us cross-check the paraphrases against what the CMO actually says, and in `v1.3.0` those fabricated outcomes were removed and replaced with the 10 real BSCS outcomes (CS01–CS10) plus the 5 common outcomes §6.1(a)–(e).

## Trust boundary

- **Inside `genai-analysis/frameworks/`** → curated paraphrases, frozen, versioned, embedded in the LLM system prompt.
- **Here** → raw source material and OCR. Useful for cross-check and audit. Never read by the runtime.

If a paraphrase drifts from the OCR, fix the paraphrase in `genai-analysis/frameworks/` and bump the bundle version. Do not change the OCR files.
